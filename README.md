# Integrative Post-GWAS Methods: Advanced Statistics, Functional Genomics, and Machine Learning
Course material and notes for the PhD course "Integrative Post-GWAS Methods: Advanced Statistics, Functional Genomics, and Machine Learning" w. Ditte Demontis Group

# Setup

## Environment

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.zshrc  # reload PATH so uv is available
uv venv
uv sync
uv pip install "git+https://github.com/arnor-sigurdsson/EIR-auto-GP.git@27928f"
jupyter lab
```

Then open e.g. the notebooks under ./notebooks
